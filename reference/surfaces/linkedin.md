# LinkedIn

Factual description of the platform — fields, order, limits, discovery mechanics. No positioning
advice: how this candidate should use LinkedIn lives in `data/surfaces/linkedin/context.md`;
generic methodology is in `policies/surfaces-framework.md`.

Character limits change; verify against the live platform before relying on an exact number.

## What it is

Professional networking, hiring, and public professional identity. Audience: recruiters, hiring
managers, peers, and anyone searching for a person or a skill.

## Profile structure

Fields in display order:

- **Headline** — one line under the name. Searchable, shown in every search result and next to
  every post/comment. ~220 characters.
- **About** — free text below the headline. ~2,600 characters. First ~2–3 lines show before a
  "see more" fold.
- **Experience** — repeated entries, ordered by end date (current first). Each entry:
  title · company · employment type · start/end date · location · description (~2,000 chars) ·
  skills · linked media/projects. Multiple positions at one company can nest under the company.
- **Top Skills** — a small pinned set (currently 5) surfaced prominently.
- **Skills** — a larger list; each can be endorsed and can be tied to specific Experience entries.
- **Banner** — image behind the profile header. Rendered text in the image is not indexed.
- Also: Featured, Recommendations, Licenses & Certifications, Education, Languages, Contact info.

## Discovery mechanics

Recruiter and member Boolean search over headline, skills, About, and Experience text. LinkedIn's
own skill taxonomy powers skill suggestions and some filtering. Posting activity affects feed
reach but not profile search.
